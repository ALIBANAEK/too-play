Règles du Jeu

Bienvenue dans le Morpion Gobblet !

  • Chaque joueur possède 3 tailles de pions : Petit, Moyen, Grand.
  • Inventaire : 2 Grands, 2 Moyens, 4 Petits.
  • Vous pouvez placer un pion sur une case vide.
  • Vous pouvez "manger" (recouvrir) un pion plus petit avec un plus grand.
  • Alignez 3 de vos pions (visibles) pour gagner !
